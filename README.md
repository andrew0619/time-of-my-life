# 時光模擬器 | Time Simulator

這是一個視覺化展示人生時間流逝的網頁應用程式。使用者可以輸入姓名、出生日期和預期壽命，應用程式將以方格形式顯示人生的時間，其中每個方格代表一個月的時光。

## 功能特點

- 簡約黑白設計風格，如同現代美術館展覽
- 輸入個人資訊（姓名、出生日期、預期壽命）
- 視覺化展示已經過去的時間和剩餘的時間
- 可調整預期壽命，即時更新視覺效果
- 支持中英文雙語切換

## 技術實現

- Next.js 框架
- React 前端庫
- TypeScript 類型系統
- Framer Motion 動畫庫
- i18next 國際化支持

## 如何啟動

1. 安裝依賴：
```bash
npm install
```

2. 啟動開發伺服器：
```bash
npm run dev
```

3. 在瀏覽器中訪問：
```
http://localhost:3000
```

## 構建生產版本

```bash
npm run build
npm start
```

## 使用說明

1. 在首頁輸入您的姓名、出生日期和預期壽命
2. 點擊「開始模擬」按鈕開始視覺化展示
3. 在模擬頁面，您可以調整預期壽命
4. 點擊右上角可切換中英文語言
5. 點擊底部的「重設」按鈕返回設置頁面
